## Brand Foundation

### Brand Colors

| Color Name       | Hex Code  | RGB                | Usage                              |
| ---------------- | --------- | ------------------ | ---------------------------------- |
| **Forest Green** | `#4B7F52` | rgb(75, 127, 82)   | Primary brand color, CTAs, headers |
| **Gold**         | `#D4AF37` | rgb(212, 175, 55)  | Accents, highlights, emphasis      |
| **Sage**         | `#7BA083` | rgb(123, 160, 131) | Secondary elements, backgrounds    |
| **Warm Sand**    | `#F6F4F1` | rgb(246, 244, 241) | Backgrounds, light areas           |
| **Charcoal**     | `#2C2C2C` | rgb(44, 44, 44)    | Body text, dark elements           |
| **White**        | `#FFFFFF` | rgb(255, 255, 255) | Cards, light backgrounds           |

### Typography

| Use Case         | Font         | Weight         | Notes                            |
| ---------------- | ------------ | -------------- | -------------------------------- |
| **Headlines**    | Crimson Text | 600 (Semibold) | Elegant, serif, traditional feel |
| **Subheads**     | Inter        | 500 (Medium)   | Clean, modern sans-serif         |
| **Body Text**    | Inter        | 400 (Regular)  | Highly readable                  |
| **CTAs/Buttons** | Inter        | 600 (Semibold) | Clear, actionable                |

**Free Font Sources:**

- Crimson Text: [Google Fonts](https://fonts.google.com/specimen/Crimson+Text)
- Inter: [Google Fonts](https://fonts.google.com/specimen/Inter)

### Logo

**File:** `/public/pathible-logo.svg`

Usage guidelines:

- Minimum clear space: 20px on all sides
- Minimum width: 120px
- Do not distort, rotate, or add effects
- On dark backgrounds, use white version (if available)

## Design Do's and Don'ts

### DO:

- Keep designs clean and uncluttered
- Use warm, natural color tones
- Leave plenty of white space
- Make text large and readable on mobile
- Use consistent font sizing across carousel slides
- Include clear CTAs on final slides
- Test readability at small sizes

### DON'T:

- Use overly religious imagery (crosses, churches, etc.) - faith is in the words
- Use cold, corporate blue tones
- Crowd text into small spaces
- Use stock photos that look generic
- Add too many decorative elements
- Use hard-to-read script fonts
- Forget mobile-first design

## Delivery Format

Please deliver:

1. All graphics as PNG files (RGB, 72 DPI for web)
2. Organized in folders by platform (Instagram, Facebook, Twitter, LinkedIn)
3. Source files (Figma, Canva, or PSD) for future edits
4. Any custom icons or elements as separate assets
